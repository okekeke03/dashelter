# DASHELTER

大雨のとき「今いる場所にとどまるべきか、避難すべきか」を判断し、避難が必要なら近くの安全な避難所まで案内する Web アプリ。

> **開発中** — チーム開発で作ったプロトタイプ(3日間・AWS Cloud9)を、個人で設計からやり直しています。

## 設計の考え方

- **避難判断はルールで決める。** 気象庁の警報・注意報とハザードマップ(浸水想定区域・土砂災害警戒区域)をもとに、「安全 / 準備 / 避難」をルールで判定します。
- **AI は説明だけを担当する。** AI には判定結果と事実データだけを渡し、理由の説明と行動アドバイスの生成に役割を限定します。AI が判定を変えることはできません。
- **AI の出力は検証する。** データにない避難所や、判定と矛盾する内容が含まれていれば採用せず、決まった文面に切り替えます。AI が使えないときもアプリは動きます。
- **取得できなかった値は「不明」と表示する。** 失敗したときに 0m・0mm のような、事実に見える値を出しません。
- **デモモード。** 晴れの日でも、大雨警報や特別警報が出ているときの動きを確認できます(画面に「デモ」と明示します)。

詳しくは [docs/design.md](docs/design.md) を参照してください。

## 構成(予定)

| フォルダ | 内容 |
|---|---|
| `web/` | 画面(静的サイト、Leaflet で地図を表示) |
| `functions/` | AI の呼び出しと気象データの中継(Cloudflare Pages Functions) |
| `scripts/` | 避難所データを整形・分割する Python スクリプト |
| `docs/` | 設計メモ |

## データの出典(予定)

- 指定緊急避難場所データ:国土地理院
- 標高:国土地理院
- 洪水浸水想定区域・土砂災害警戒区域など:重ねるハザードマップ(国土交通省・国土地理院)
- 警報・注意報:気象庁
- 雨量:Open-Meteo

各データの利用規約に従い、公開時に正式な出典表記を載せます。

## 注意

このアプリは避難判断の参考情報を提供するもので、自治体や気象庁が出す情報の代わりにはなりません。実際の避難は、自治体の避難指示などに従ってください。
